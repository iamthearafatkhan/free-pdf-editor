# FreePDF Editor

**Free browser-based PDF editor — edit text in any PDF like Word.**

🔗 **Live:** [FREE PDF Editor](https://pdfeditnow.pages.dev/)

## Why this exists

Most online PDF editors demand a subscription. This one doesn't. It runs entirely
in your browser — your file never leaves your computer.

## Features

- ✏️ Edit existing text inside any PDF
- ➕ Add new text anywhere on the page
- 🔄 Reflow like Word — delete a line and the text below slides up
- 🎨 Font matching (Arial, Times, Courier, Calibri)
- 💾 Save as PDF or DOCX
- 🔒 100% private — no uploads, no accounts, no tracking
